# Surface: calculator web app (all tabs)

Scope: the whole web app shell and every tab. Mode: Operate.
Audience and job: MapleRoyals players (followers and tuners) computing a low-APR HP washing plan on desktop beside the game client, often in the evening. Constraints: bilingual zh/en switch, light and dark appearance with a switch (default follows the system), the estimates disclaimer stays visible, calculation core untouched.

## Direction contract

THESIS: The plan is a field specimen. A result is a specimen label you can read at a glance; policy behaviour is a field guide's dichotomous key. Refuses the generic dark gaming dashboard and the parchment-and-serif game skin.

OWN-WORLD: Herbarium mount board in sage grey-green (#e9ede4) with ink-green structure (#1f2a22), maple crimson (#c2381f) for the one action, ochre (#d98a1c) for specimen numbers and caution, moss (#3f7a3a) for reached states. Dark appearance is the specimen cabinet at night: deep moss-black ground, bone text, same crimson and ochre. Square corners, 1px ink rules, labels set in Archivo with tabular figures; CJK deliberately uses the system Traditional Chinese face (Microsoft JhengHei / PingFang TC / Noto Sans TC where installed) to avoid shipping a multi-megabyte CJK font.

STORY: The player sets goal and job, presses 執行最佳化, reads the specimen label (policy, base INT, MP wash end, APR, reached or not), then follows the key and the level table in game.

FIRST VIEWPORT: Ink-green top bar with the product name (MapleRoyals in maple orange), language and appearance switches at right; tabs hang from the bar, the active one cut into the mount board. Optimize: form column left (420px) with a full-width crimson run button; results right, led by the specimen label (ochre number tag, crimson headline line, moss stamp, capacity bar, four-figure ruled strip), then the key, then the plan table.

FORM: Field-guide specimen sheet, candidate 5 of 7 (assigned by roll). seed:cbeab8c4e83edca4. Raises: numbers on one grid (Crouwel), capacity bar for HP target (j-card), states as printed marks: filled reached, hollow not reached, struck stale (reference rail).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
